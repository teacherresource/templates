# Math Speed Drills

Printable math fact drills: 100 facts to a page, any number families you type in, with an
optional learning row of the day's facts worked out at the top and a matching answer key.

**To use it:** download [`math-speed-drills.html`](math-speed-drills.html) and open it in Chrome,
Edge, Firefox or Safari. Set it up in the panel on the left, then press **Print**. Nothing is
saved between visits, so keep the file itself and re-enter the settings, which takes a moment.

## What it does

- **Today's facts:** type the facts you're learning, such as `7x8, 8x7, 7x9, 9x7`, and they print
  in a boxed row at the top of the sheet with the answers filled in. Up to 12 facts, which wrap
  onto a second row on their own. Any operation works: `15-8`, `56/7`, `9+6`.
- **Drill only those facts:** builds the whole page from just the facts in that row, shuffled so
  each one comes up about the same number of times. Four facts on a 100-fact page is 25 reps each.
  Turn it off and the row stays at the top as a reference while the page drills the full families.
- **Number families:** type anything — `1-16`, `3,6,9`, `7`, `2-5, 11, 20-25`. "Paired with" sets
  the other number in each fact, so families `7` paired with `0-12` gives exactly the 7s.
- **Operations:** addition, subtraction, multiplication and division, alone or mixed. Subtraction
  and division are built as the inverse of addition and multiplication, so answers stay whole and
  never go negative unless you ask for it. Nothing is ever divided by zero.
- **Problem style:** stacked (the default), with division drawn as a real long division bracket —
  divisor, curved bracket, bar over the dividend, quotient above the bar. Or across, as `7 × 8 =`.
- **Row numbers** down the left side, so you can say "start on row 4" without anyone counting.
  Or number every problem, or neither.
- **Answer key:** switch the page to show answers, or keep it blank and have a matching key page
  print behind each worksheet. Answers print in red so keys stand out in a stack.
- **Several worksheets at once:** each gets its own letter (Set A, Set B…) with different facts,
  and its key is labelled to match. All the sheets in a set are sized alike.
- **Fits the page by itself:** type size and the number of columns are worked out from what you
  asked for — multiplication to 16 lands on the classic 10 × 10 grid, long division on a wider
  one. A slider nudges the size, a dropdown overrides the columns, and a warning appears above
  the sheet if anything spills onto a second page.
- **Heading:** title, name and date lines, a score box out of the number of facts, and a time
  limit such as "5 minutes". All of it optional.

**Print settings:** margins **Default** or **None**, scale **100%**, headers and footers off.
Turn on background graphics to keep the shaded learning row and the red answer key; without it
both still print, just in grey. Choose **Save as PDF** in the print dialog to make a PDF.

## Fonts when offline

Problems are set in Atkinson Hyperlegible, a typeface drawn for legibility, loaded from Google
Fonts. Without an internet connection the page still works and falls back to Verdana, so the
numbers look slightly different but stay aligned and readable.

## Editing

This template is a single file with no `src/` folder: edit `math-speed-drills.html` directly.
