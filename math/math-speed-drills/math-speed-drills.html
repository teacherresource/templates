Math Facts Speed Drill Builder

Set it up on the left, print from the right. Nothing is saved — bookmark or save this file to keep it.

Today’s facts

Write them out: 7x8, 8x7, 6x9. Works with any operation — 15-8, 56/7, 9+6. Up to 12.

Operations

Pick more than one to build a mixed drill.

Number families

Type anything: 1-16, 3,6,9, 7, 2-5, 11, 20-25.

The other number in each fact. For the 7s times 0–12, set families to 7 and this to 0-12.

Operations and families are paused — the page is drilling today’s facts instead. Uncheck “Drill only these facts” to use them again.

Fact rules

Subtraction and division are built as the inverse of addition and multiplication, so answers stay whole and clean.

Page layout

Row numbers let you say “start on row 4” without counting.

Sheet

Each worksheet gets its own letter (A, B, C…) and a different set of facts.

Answers

Answers print in red so keys are easy to spot in a stack.
